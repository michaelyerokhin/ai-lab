# Project rules
- Python 3.11, one folder per lab: week1/, week2/ ...
- Secrets go in a .env file (never committed). Add .env to .gitignore.
- Every script gets a short README and at least one test (pytest).
- Prefer Entra ID auth (DefaultAzureCredential) over API keys.
- Explain any Azure service choice in a comment.
- Before finishing, run the code and the tests and show the output.
